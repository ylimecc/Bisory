Preguntas frecuentes

Antes de descargar

¿Windows muestra una advertencia al abrir Bisory?
Solo si usas el instalador o la versión portátil, porque todavía no tienen firma digital. Para continuar, selecciona «Más información» y después «Ejecutar de todas formas». La versión de Microsoft Store no muestra este aviso.
¿Qué capturadora necesito?
Cualquier capturadora USB con entrada HDMI. Bisory se probó con modelos económicos con chip MS2130, en Full HD a 60 cuadros por segundo. Si tu computadora tiene puertos USB 3.0 (suelen ser de color azul), conéctala en uno de ellos.
¿Qué versión me conviene?
Microsoft Store (recomendada): se instala y se actualiza sola, sin avisos de Windows. Instalador: funciona igual, pero las actualizaciones se descargan manualmente. Versión portátil: un solo archivo que se abre sin instalar nada, útil para llevarlo en una memoria USB.
¿Dónde se guardan mis videos y capturas?
En tu carpeta de Descargas. Para usar otra, abre Ajustes y selecciona «Cambiar carpeta».
¿Hay retraso en la imagen?
El retraso lo determina la capturadora, no Bisory. Con un modelo MS2130 es de unas décimas de segundo, suficiente para juegos de aventura, de plataformas o para jugar de forma casual. En juegos de pelea competitivos conviene jugar en la televisión y usar Bisory solo para grabar.
